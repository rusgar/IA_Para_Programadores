🔑 Conceptos Clave de APIs de IA

Términos Fundamentales:

  • Tokens: Unidad de medida del texto (≈4 caracteres o 0.75 palabras)
  • Context Window: Cantidad máxima de tokens en una conversación
  • Temperature: Control de aleatoriedad (0=determinista, 1=creativo)
  • Top-p: Sampling nucleus, alternativa a temperature
  • Max Tokens: Límite de tokens en la respuesta
  • System Prompt: Instrucciones base del comportamiento del modelo
  • Few-shot Learning: Proporcionar ejemplos en el prompt
  • Embeddings: Representaciones vectoriales de texto para búsqueda semántica

async function analyzeSentiment(text) {
  const response = await openai.chat.completions.create({
    model: "gpt-4o-mini",
    messages: [
      {
        role: "system",
        content: `Analiza el sentimiento del texto y responde SOLO con JSON:
        {
          "sentiment": "positive" | "negative" | "neutral",
          "confidence": 0-1,
          "emotions": ["joy", "anger", "sadness", etc],

        }`
      },
      { role: "user", content: text }

  });

}

🔍 Búsqueda Semántica con Embeddings

Concepte: Embeddings

Los embeddings convierten texto en vectores numéricos que capturan su significado semántico. Textos similares tienen vectores cercanos.

Ejemplo de Uso:

// 1. Generar embeddings para documentos
async function createEmbedding(text) {
  const response = await openai.embeddings.create({
    model: "text-embedding-3-small",
    input: text
  });
  return response.data[0].embedding; // Array de 1536 números
}

// 2. Buscar documentos similares (usando similitud coseno)
function cosineSimilarity(vecA, vecB) {
  const dotProduct = vecA.reduce((sum, a, i) => sum + a * vecB[i], 0);
  const magA = Math.sqrt(vecA.reduce((sum, a) => sum + a * a, 0));
  const magB = Math.sqrt(vecB.reduce((sum, b) => sum + b * b, 0));
  return dotProduct / (magA * magB);
}

// 3. Buscar
const query = "cómo cocinar pasta";
const queryEmbedding = await createEmbedding(query);
const results = documents.map(doc => ({
  doc,
  similarity: cosineSimilarity(queryEmbedding, doc.embedding)
})).sort((a, b) => b.similarity - a.similarity);

💡 Implementación Completa de Chatbot

Backend - Node.js con Express:

import express from 'express';
import OpenAI from 'openai';

const app = express();
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// Almacenar conversaciones (en producción: usar Redis/DB)
const conversations = new Map();

app.post('/api/chat', async (req, res) => {
  const { message, sessionId } = req.body;
  
  // Obtener o crear historial de conversación
  if (!conversations.has(sessionId)) {
    conversations.set(sessionId, [
      {
        role: "system",
        content: "Eres un asistente útil y amigable. Responde de forma clara y concisa."
      }
    ]);
  }
  
  const history = conversations.get(sessionId);
  history.push({ role: "user", content: message });
  
  try {
    const completion = await openai.chat.completions.create({
      model: "gpt-4o-mini",
      messages: history,
      temperature: 0.7,
      max_tokens: 500,
      stream: true // Streaming para respuestas en tiempo real
    });
    
    // Configurar SSE para streaming
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');
    
    let fullResponse = '';
    
    for await (const chunk of completion) {
      const content = chunk.choices[0]?.delta?.content || '';
      fullResponse += content;
      res.write(`data: ${JSON.stringify({ content })}\n\n`);
    }
    
    // Guardar respuesta completa en historial
    history.push({ role: "assistant", content: fullResponse });
    res.write('data: [DONE]\n\n');
    res.end();
    
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

app.listen(3000, () => console.log('Chatbot API running on port 3000'));

6️⃣ Optimización de Costos y Rendimiento

💰 Gestión de Costos en APIs de IA

Las APIs de IA pueden ser costosas en producción. Es crucial implementar estrategias de optimización y control de gastos.

📊 Estrategias de Reducción de Costos

Estrategia Ahorro Estimado Implementación
Usar modelos más pequeños 50-90% GPT-4o-mini en lugar de GPT-4 para tareas simples
Caching de respuestas 30-70% Redis/Memcached para queries frecuentes
Prompt optimization 20-40% Prompts más concisos y específicos
Batch processing 15-30% Agrupar múltiples requests en uno
Streaming responses Variable Mejor UX, no ahorra pero mejora percepción
Rate limiting Previene abusos Límites por usuario/IP

import Redis from 'ioredis';

async function cachedAIRequest(prompt, options = {}) {
  // Generar hash único del prompt
  const cacheKey = crypto
    .createHash('md5')
    .update(JSON.stringify({ prompt, options }))
    .digest('hex');
  
  // Intentar obtener de caché
  const cached = await redis.get(`ai:${cacheKey}`);
  if (cached) {
    console.log('✅ Cache HIT - Ahorrando llamada a API');
    return JSON.parse(cached);
  }
  
  console.log('❌ Cache MISS - Llamando a API');
  
  // Llamar a API
  const response = await openai.chat.completions.create({
    model: options.model || "gpt-4o-mini",
    messages: [{ role: "user", content: prompt }],
    ...options
  });
  
  const result = response.choices[0].message.content;
  
  // Guardar en caché (24 horas)
  await redis.setex(
    `ai:${cacheKey}`,
    86400,
    JSON.stringify(result)
  );
  
  return result;
}

// Uso
const result = await cachedAIRequest(
  "¿Cuál es la capital de Francia?",
  { model: "gpt-4o-mini" }
);

🎯 Mejores Prácticas de Optimización

✅ Checklist de Optimización:

  • ☑️ Modelo adecuado: Usa GPT-4o-mini para tareas simples
  • ☑️ Temperatura correcta: 0.3 para consistencia, 0.7+ para creatividad
  • ☑️ Max tokens optimizado: No pidas más tokens de los necesarios
  • ☑️ System prompt eficiente: Instrucciones claras y concisas
  • ☑️ Few-shot cuando ayude: Proporciona ejemplos solo si mejoran resultado
  • ☑️ Streaming cuando sea posible: Mejor UX, mismo costo
  • ☑️ Monitoreo constante: Dashboards de uso y costos
  • ☑️ Alertas de gasto: Notificaciones cuando se exceden límites

📈 Monitoreo y Analytics

Métricas Clave a Seguir:

  • Costo por request: Promedio de gasto por llamada
  • Cache hit rate: % de requests servidos desde caché
  • Tokens por request: Media de tokens consumidos
  • Latencia: Tiempo de respuesta (P50, P95, P99)
  • Error rate: % de llamadas fallidas
  • Cost per user: Gasto promedio por usuario activo
